# Saad EPG — دليل البرامج العربي لريسيفرات Enigma2

(كان اسمه سابقًا ArabEPG، والإعدادات والربط تُنقل تلقائيًا للاسم الجديد.)

بلوجين يضيف جدول البرامج (EPG) للقنوات التي لا ترسل دليلًا على القمر، مع سيرفر سحابي مجاني على GitHub يجمع الدليل يوميًا.

**الأقمار المدعومة:** نايل سات 7W، عرب سات / بدر 26E، هوت بيرد 13E، يوتلسات 16E، البلغاري 1.9E، آموس 4W.

## كيف يعمل
```
GitHub Actions (مرتين يوميًا)                الريسيفر
┌──────────────────────────────┐            ┌──────────────────────────────┐
│ يجمع من: شاهد، OSN، beIN،    │  ملفات     │ 1. يعرف أقمار باقاتك تلقائيًا │
│ السينما.كوم، روتانا، رؤيا، ART │ ─────────► │ 2. يربط كل قناة بمصدرها       │
│ الجزيرة + ملفات أوروبية       │  صغيرة     │ 3. يحمّل ما يحتاجه فقط         │
│ ويضغطها في فرع epg            │            │ 4. لو فشل مصدر → بديل → نسخة   │
└──────────────────────────────┘            │    احتياطية                    │
                                             └──────────────────────────────┘
```

## إعداد المستودع (مرة واحدة)
1. على GitHub أنشئ مستودعًا جديدًا باسم **ArabEPG** ونوعه **Public** (عام). الريسيفر لا يستطيع القراءة من مستودع خاص.
2. ارفع كل محتويات هذا المجلد إلى المستودع، **بما فيها مجلد `.github`**:
   - من الكمبيوتر: صفحة المستودع ← **Add file ← Upload files** ثم اسحب كل الملفات والمجلدات.
     في ويندوز، لو لم يظهر مجلد `.github`، فعّل إظهار الملفات المخفية.
   - أو بالأوامر:
     ```
     git init && git add -A && git commit -m "ArabEPG 3.0"
     git branch -M main
     git remote add origin https://github.com/Saadmelshepiny/ArabEPG.git
     git push -u origin main
     ```
3. افتح تبويب **Actions** في المستودع، واضغط زر تفعيل الـ workflows لو ظهر لك.
4. اختر **Build EPG** ثم **Run workflow**. أول تشغيل يأخذ من 20 إلى 40 دقيقة.
5. بعد انتهائه سيظهر فرع اسمه **epg**، وفيه ملف `status.json` يوضح ما نجح وما فشل لكل مصدر.

بعد ذلك يعمل وحده مرتين يوميًا (04:17 و 16:17 بتوقيت القاهرة).

### لو فشل النشر بخطأ صلاحيات
Settings ← Actions ← General ← Workflow permissions ← اختر **Read and write permissions** ← Save.

### ملاحظة عن GitHub
GitHub يوقف الـ workflows المجدولة في المستودعات التي لم يحدث فيها نشاط لمدة 60 يومًا، ويرسل لك إيميل قبلها. لو حدث ذلك، افتح Actions وفعّل **Build EPG** من جديد.

## تثبيت البلوجين
```
opkg remove enigma2-plugin-extensions-arabepg   # لو كان الإصدار القديم مثبتًا
opkg install /tmp/enigma2-plugin-extensions-saadepg_1.0_all.ipk
killall -9 enigma2
```
ملف الـ ipk موجود في مجلد `release`. التحديثات القادمة تتم من داخل البلوجين: **"التحقق من تحديث البلوجين"**.

## بدون سحابة أيضًا
حتى قبل تشغيل السحابة، البلوجين يحمّل مباشرة من epgshare01 ملفات صغيرة: الإمارات (دبي، أبوظبي، الشارقة، AD Sports، Dubai Sports...)، beIN، مصر، السعودية.

## استيراد ملفات EPG خاصة بك
ضع أي ملف XMLTV (`.xml` أو `.xml.gz`) في أحد هذه المجلدات:
- `/media/hdd/ArabEPG/import/`
- `/media/usb/ArabEPG/import/`
- `/etc/enigma2/ArabEPG/import/`

البلوجين يقرأ أسماء القنوات في الملف ويربطها تلقائيًا بقنواتك في التحديث التالي.

## هيكل المستودع
| المسار | المحتوى |
|---|---|
| `plugin/SaadEPG/` | كود البلوجين |

| `tools/aliases.json` | أسماء القنوات كما تظهر على الأقمار (لتحسين الربط) |
| `tools/build_ipk.py` | يبني ملف الـ ipk |
| `cloud/build.py` | يجهّز ملفات الدليل المضغوطة والفهرس |

مصادر الجمع مبنية على المشروع المفتوح [iptv-org/epg](https://github.com/iptv-org/epg) وملفات [epgshare01](https://epgshare01.online).

## لغة الدليل
الإعدادات ← **لغة الدليل للقنوات العربية**:
- **عربي فقط (الافتراضي):** القناة العربية لا تأخذ إلا دليلًا عناوينه بالعربي من مصدر عربي موثوق. لو لم يوجد، تبقى بدون تحديث بدل أن تأخذ دليلًا إنجليزيًا.
- **عربي أولًا ثم إنجليزي:** يقبل الإنجليزي لو لم يجد عربيًا.
- **أي لغة:** بدون فلترة.

القنوات الأجنبية وقنوات English/French لا تُطبَّق عليها الفلترة.

## الجديد في 4.0
- **ربط بالمرجع يتعلم:** كل قناة تؤكدها يدويا أو يتأكد ربطها بمقارنة دليل القمر يُحفظ رقم خدمتها، وأي قناة بنفس الرقم تُربط فورا. ويمكن مشاركة القائمة عبر `cloud/linked_refs.json` (زر "تصدير الربط المؤكد").
- **أسرع:** المصادر تُحمَّل بالتوازي، وملفات XMLTV تُحفظ 6 ساعات.
- **دليل عند فتح القناة:** لو فتحت قناة بدون EPG، يجهّز البلوجين دليلها في الخلفية خلال ثوان.
- **ترجمة الدليل الإنجليزي إلى العربية:** الإعدادات ← لغة الدليل ← "عربي + ترجمة". الترجمة عبر MyMemory المجاني (أو سيرفر LibreTranslate)، وكل عنوان يُترجم مرة واحدة ويُحفظ.

## الإصدار 1.5
- إصلاح تجمد الريسيفر عدة ثوان عند بدء كل تحديث (ومنه تجهيز دليل القناة المفتوحة): النسخة الاحتياطية صارت ملفا صغيرا لكل قناة، ومواعيد البرامج المضافة في ملف صغير منفصل.
- أسماء إضافية: KSA Sports 1، المصرية، السعودية للقرآن والسنة، العربي 2، الرسالة، الوطنية 1 و 2، ياس، البحرين الرياضية.

## الإصدار 1.4
- ترجمة دليل القمر نفسه للقنوات الأجنبية غير المربوطة (هوت بيرد، يوتلسات 16، أسترا 23.5 وغيرها) إلى الإنجليزية، بقواميس العناوين التي تبنيها السحابة لكل لغة.
- كتابة لاتينية تلقائية لأسماء القنوات اليونانية.

## الإصدار 1.3
- القنوات الإسرائيلية (آموس 4W) والبلغارية تُربط بأدلتها: أسماء إنجليزية للقنوات العبرية، وكتابة لاتينية تلقائية للأسماء السيريلية، فيظهر دليلها بالإنجليزية.
- عند تساوي نسبة الربط يُفضَّل دليل القمر نفسه (مثلا Sport 5 على آموس يأخذ الدليل الإسرائيلي وليس الأوكراني).
- صحة الدليل تجمع نتائج كل التحديثات (المراحل وتحديث القناة الواحدة) بدل آخر تحديث فقط.
- زر أسفل/أعلى في "الآن وبعده" والقنوات ينزل سطرا واحدا.
- "تحديث دليل البرامج الآن" يجلب آخر تجميع للسحابة فورا، والملفات تُحدَّث تلقائيا عند كل تجميع جديد.

## الإصدار 1.2
- شاشات بتصميم جديد: جداول بأعمدة ومربعات (الآن وبعده، القنوات، الإحصائيات، الباقات، القوائم)، ساعة رقمية، وبطاقات أرقام.
- أدلة XMLTV لأقمار وباقات أجنبية أكثر (ألمانيا، النمسا، سويسرا، هولندا، بلجيكا، إسبانيا، البرتغال، التشيك، سلوفاكيا، تركيا، الدول الإسكندنافية، البلطيق، قبرص، أيرلندا، Sport Klub) وأقمار جديدة (أسترا 19.2/23.5/28.2/4.8، يوتلسات 3/7/9/36، هيلاس سات، تركسات، ثور، هيسباسات).
- ترجمة أدلة القنوات الأجنبية إلى الإنجليزية في السحابة (Argos/CTranslate2، بدون حد يومي): العناوين ثم التصنيفات ثم وصف أول 36 ساعة. الإعدادات ← "لغة دليل القنوات الأجنبية".
- نسخة احتياطية أسبوعية تلقائية على الهارد (مع النسخة السابقة في previous/)، واستعادة تلقائية بعد تثبيت البلوجين على ريسيفر جديد أو بعد التفليش.
- إصلاح: عدد "مربوطة" في الإحصائيات كان يظهر 0 بعد تحديث قناة واحدة.

## الإصدار 1.1
- مصادر رسمية جديدة: LBCI (لبنان)، التلفزة التونسية، TRT عربي.

## الإصدار 1.0 (Saad EPG)
- الاسم الجديد Saad EPG، مع نقل كل الإعدادات والربط من ArabEPG.
- **ميعادان للتحديث اليومي**، و**التحديث على مراحل** (2–4 مراحل بينها 10–60 دقيقة) بترتيب باقاتك.
- قائمة مبسطة: تحديث / القنوات / صحة الدليل / الإعدادات / أدوات متقدمة.
- بجانب كل قناة نوع مصدرها: رسمي / عربي / ملف / منسوخ.
- حفظ ملف الدليل epg.dat على الهارد.
- السحابة تحفظ صفحات المواقع الرسمية العربية (probe/) لإضافة مصادر رسمية جديدة.

## الجديد في 6.0
- **كاشف التسرب:** بعد كل استيراد يفحص البلوجين هل ظهر الدليل على قناة أخرى (بعض الريسيفرات تحفظ الدليل برقم الخدمة فقط). لو حدث، يمسحه ويوقف الدليل لتلك القناة 30 يومًا، ويكتب التفاصيل في السجل.
- **منع تعارض رقم الخدمة:** القنوات المختلفة التي تتشارك نفس رقم الخدمة لا يضاف لها دليل.
- **زر "الدليل خطأ لهذه القناة"** في قائمة معلومات البرنامج أثناء المشاهدة.
- **إخفاء دليل القمر الخطأ** لقناة معينة (من شاشة القنوات).
- **اختيار الباقات** التي يحدّثها البلوجين.
- **السحابة:** ملف صغير بالقنوات العربية الموجودة في الملفات الأوروبية فقط (2M، ART Cinema...).
- **صحة الدليل**، **نسخ احتياطي واسترجاع**، **مسح ذاكرة الترجمة القديمة**.

## الجديد في 5.0
- **التحقق بمواعيد البرامج:** كل ربط يُقارن بدليل القمر في العنوان ومواعيد بداية البرامج (لا يعتمد على اللغة). الربط الذي لا يطابق يُرفض ولا يُستورد، ويُمسح دليله الخطأ القديم.
- **تصحيح فرق التوقيت تلقائيًا** (±1 إلى 3 ساعات).
- **منع خلط المناطق:** قناة دليلها على القمر بلغة أوروبية لا تُربط بمصدر عربي، والعكس.
- **مستوى الأمان:** الربط غير المؤكد الضعيف لا يُستورد، ويظهر بعلامة [?] في "تحتاج مراجعة".
- **السحابة:** 5 أيام بدل 3، السينما.كوم على 4 دفعات مع إعادة محاولة، وكل الإعدادات في `cloud/sources.json`.
- **ترجمة في السحابة:** GitHub يترجم العناوين الإنجليزية للقنوات العربية ببرنامج Argos Translate (بلا حدود)، والريسيفر ينزّل القاموس جاهزًا.

## الجديد في 4.1
- **نسخ الدليل بين نسخ نفس القناة:** لو القناة موجودة أكثر من مرة في **نفس الباقة** (SD و HD، أو على قمرين) ونسخة واحدة فقط لها دليل، يُنسخ الدليل للنسخة الفارغة. شروط النسخ:
  - نفس الباقة فقط، لأن نفس الاسم في باقة أخرى قد يكون بثًا مختلفًا.
  - الاسم متطابق بعد حذف HD/SD/FHD/4K، والأرقام متطابقة.
  - الأسماء التي تدل على بث مختلف لا تُنسخ أبدًا: ‎+1/+2، Europe، USA، Feed...
  - لو قاعدة المراجع تقول إنهما قناتان مختلفتان، لا يُنسخ.
  - لو النسخة الفارغة تعرض عنوان البرنامج الحالي، يجب أن يطابق النسخة الأخرى.
  - لو أكثر من نسخة لها دليل، يجب أن تتفق فيما بينها.
  يمكن إيقافه من الإعدادات، وكل قناة لم تُنسخ وسبب ذلك يظهر في السجل.
- **مصدر رسمي جديد:** SNRT للقنوات المغربية.

## الربط اليدوي
من داخل البلوجين: **طريقة الربط اليدوي للقنوات** (شرح كامل على الشاشة). باختصار:
القنوات والربط الذكي ← الأصفر للفلتر ← اختر القناة ← الأزرق للمعاينة ← OK لاختيار المصدر أو البحث بالاسم ← الأخضر لتحديث القناة.

## مسح الدليل القديم
**مسح دليل البلوجين وإعادة تحميله** يمسح ما أضافه البلوجين فقط، ثم يعيد التحميل بالقواعد الجديدة. لو كانت الصورة لا تسمح بمسح قناة واحدة، يعرض مسح الـ EPG كله.
